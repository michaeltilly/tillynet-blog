## Overview

Earned the Cisco Certified Network Professional Enterprise (CCNP Enterprise) certification by obtaining both the Cisco Certified Specialist - Enterprise Core (ENCOR 350-401) and the Cisco Certified DevNet Specialist - Enterprise Automation and Programmability (ENAUTO 300-435). This involved building real lab environments in EVE-NG, configuring enterprise routing protocols, designing SD-Access fabrics, and mastering network automation with Python and APIs.

## Certification Track

| Exam | Code | Focus | Status |
|------|------|-------|--------|
| ENCOR | 350-401 | Enterprise core technologies | Achieved |
| ENAUTO (DevNet Specialist) | 300-435 | Enterprise automation and programmability | Achieved |

## ENCOR Topics

- **Routing Protocols:** OSPF, IS-IS, BGP configuration and troubleshooting
- **SD-Access:** Fabric design with Cat9kv in EVE-NG
- **Infrastructure Security:** 802.1X, MACsec, TrustSec
- **Virtualization:** VRF, GRE tunnels, LISP

## ENAUTO Topics

- **Network Automation:** Python scripting for Cisco devices
- **APIs:** RESTCONF, NETCONF, DNA Center APIs
- **SD-WAN:** Viptela SDK and automation
- **Frameworks:** Flask for network automation tools

## Lab Environment

All labs run on EVE-NG with Cisco IOS-XE images (Cat9kv). Configurations are documented and version-controlled for reproducibility.
